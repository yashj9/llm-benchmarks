Read the numbers correctly

Quality ≠ reliability

Quality is a tier-weighted pass rate on coding, tools/MCP, and contest coding. Design ratings are separate. Dyno reliability measures its own practical tasks—it is not the Quality score.

Same protocol, shared tests

The combined view reuses the local arena’s shared suite versions and case sets. Standard: thinking off, 8,192 output tokens, 18 auto-scored tests plus 3 manual design tasks. Confidence intervals are 90% bootstrap intervals; small differences are not decisive.

Speed and balanced score

Short speed uses prompts ≤16K; long speed ≥64K. Setup groups keep model, engine, context, thinking and GPU placement separate. Balanced score: 70% quality + 30% logarithmic speed (10–100 tok/s, capped at 100). It is a preference score, not a universal rank.

History stays honest

Failed, cancelled, archived and non-standard runs remain in history. Archives are not ranked. Missing settings stay unknown. Token-capped answers count as misses where the original scorer says so. Strata’s Dyno reliability is budget-limited; its Quality run uses a different output budget and thinking setting.

Prefill and resource evidence

* Observed prefill, not verified engine throughput

Cold/fresh and hot/repeat use the saved paired 260-record probe. Rates are prompt tokens divided by time to first token (TTFT), including request overhead. The repeated prefix may benefit from a cache, but these runs did not expose verified cache hits. "Cold" is a fresh prefix, not a model reload. Long prefill is the battery’s ≥64K bucket with mixed cache states. Missing pairs remain missing.

Whole-system resource comparison

RAM and GPU VRAM are absolute system/device usage, not isolated model allocations. Power is CPU package plus the two NVIDIA GPUs, not wall power. Compare equal contexts, thinking settings and workloads. Dyno uses post-load samples; Quality uses its separate job load/run/unload capture. Setup groups take medians of session means, maximum peaks and minimum RAM headroom. Dash means a sensor or capture was not recorded.
